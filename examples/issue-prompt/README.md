# Example Issue Prompt

`JOB_INSIGHT_ISSUE_PROMPT.md` is an example custom issue prompt that controls the format and content of AI-generated GitHub/Jira issues.

## Usage

Copy this file into your analyzed repository:

```bash
cp JOB_INSIGHT_ISSUE_PROMPT.md /path/to/your-repo/.rootcoz/ROOTCOZ_ISSUE_PROMPT.md
```

Edit the copy to match your project's issue conventions (title format, required sections, labels, etc.).

See [AGENTS.md](../../AGENTS.md#project-customization-rootcoz-folder) for details on the `.rootcoz/` convention.
